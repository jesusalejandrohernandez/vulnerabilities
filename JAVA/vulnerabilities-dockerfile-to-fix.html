Config Scan Vulnerabilities

Result Type: dockerfile

Title: 'apk add' is missing '--no-cache'

Type: Dockerfile Security Check

Severity: HIGH

Description: You should use 'apk add' with '--no-cache' to clean package cached data and reduce image size.

Resolution: Add '--no-cache' to 'apk add' in Dockerfile

References: https://github.com/gliderlabs/docker-alpine/blob/master/docs/usage.md#disabling-cache, https://avd.aquasec.com/misconfig/ds025
